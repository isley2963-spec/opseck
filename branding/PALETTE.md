# Zombie OS palette: "Toxic Glass"

Acid-green radioactive accent on near-black glass (dark) or pale mint glass (light).
Used by the boot splash now and by the Plasma theme in the next stage.

| Token        | Dark (default)                 | Light                          |
|--------------|--------------------------------|--------------------------------|
| base         | `#080C09`                      | `#EDF3E8`                      |
| glass        | `rgba(16, 24, 18, 0.55)`       | `rgba(255, 255, 255, 0.55)`    |
| glass border | `rgba(155, 255, 58, 0.18)`     | `rgba(30, 70, 20, 0.15)`       |
| text         | `#E8F5E0`                      | `#0F1A0C`                      |
| muted text   | `#8FA38A`                      | `#4F6149`                      |
| accent       | `#9BFF3A` (acid green)         | `#3FA011`                      |
| hazard       | `#FFD60A`                      | `#C79A00`                      |
| danger       | `#FF4545` (Panic Wipe, errors) | `#D62828`                      |

Window dots (mac style): close `#FF4545`, minimise `#FFD60A`, maximise `#9BFF3A`.
Blur: 24 px, saturation boost 1.4, corner radius 14 px.
